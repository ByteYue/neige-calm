Planner + Assistant: commit ONE user-intent update to the track report in ONE call — an ordered list of ops and an optional new `summary`, under a single `message`. It takes no revisions: the kernel anchors every op to what THIS session last read of the report with `calm.report.read` (a read that returned `text`), checked inside the write. `neige cat` is a view and anchors nothing. Default path: read the sections you will change (`select: { sections: ["H1 text"] }`), then commit section ops. `{ op: "replace", section, markdown }` rewrites one H1 section (its heading block plus the blocks up to the next H1) with `calm.report.write_markdown` rules bounded to that section: `markdown` is the whole section starting with its `# ` heading line and holding no other H1; the `<!-- neige:b_x -->` marker lines of your read pin blocks to their ids (a marker naming a block outside the section is refused), a `neige-block` fence kept verbatim is kept, edited is updated, removed is deleted. Replacing a section that is absent but declared by the report's contract creates it at its declared position; an undeclared one is refused with the declared sections. `{ op: "delete", section }` removes the whole section. Block ops: `{ op: "upsert", id, kind, markdown|payload }` replaces a block, `{ op: "upsert", kind, markdown|payload, position? }` creates one, `{ op: "delete", id }`, `{ op: "move", id, to_index }`. A section or block this session has not read is refused (-32602) until you read it. If another writer changed a section or block after your read, the commit is refused -32001 naming it: re-read that section, merge, and retry. Only a commit with `summary`, a created or moved block, or a created section also checks the whole document: any edit anywhere since your latest read refuses it -32001. What your own commit or `calm.report.write_markdown` wrote counts as read, so you can write again without re-reading; another writer's change in between is still -32001. An unknown parameter is refused -32602. Ops apply in order; any failure (-32001 conflict, -32602 invalid content) aborts the WHOLE commit — nothing is written and no event is emitted. Each block id and each section may appear in at most ONE op per commit. `ops` may be empty when only `summary` changes. `{ op: "delete", id }` naming a live task block retires it (the block is removed and its task withdrawn); a section `replace` or `delete` that would drop a live task is refused. `task` blocks are the Planner's: an Assistant commit that creates, changes or deletes one is refused as a whole. Returns `{ updated_at, docRev, blocks: [{ id, kind, rev }] }` — the full post-commit block index.
